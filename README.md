## 🎯 Combat deep dive

<table>
<tr><td width="50%" valign="top">

**Silent assist**

The correction is computed on approach and applied on the bite frame, so the camera stays where
you left it. On a recorded clip there is no visible pull — only a suspicious hit rate.

`fov 45` · `smooth 0.35` · `bone neck`

</td><td width="50%" valign="top">

**Hitbox + range gate**

The real damage capsule is drawn and the bite is held until that capsule is genuinely inside
reach. Misses stop being a timing lottery and become a positioning mistake.

`hitbox on` · `gate 0.4 m`

</td></tr>
<tr><td valign="top">

**Pounce marker**

Window, angle and predicted landing point for pounce-capable species. Reads out of reach, so you
commit on information instead of reflex.

</td><td valign="top">

**Grab helper**

Holds a grab-angle readout and drops the correction the moment the hold connects, so the drag
stays clean.

</td></tr>

## 🛡 EAC surface

Evrima runs **Easy Anti-Cheat** (EOS build), Legacy the older EAC setup. This build is fully
external: it reads and writes the process from outside — no driver, no kernel component, nothing
in the module list at boot.

| Surface | This build | Driver-based |
|---|---|---|
| Kernel driver | none | loaded, signed or not |
| Injection | none | yes |
| Boot-time scan target | process memory | driver + memory |
| What a patch breaks | offsets | driver + offsets |
| Recovery | tag ≤48 h | often a new bypass |

**Undetected as of `2026-11-23`.** A dated claim, so it ages honestly — not a ban guarantee.
Re-check the badge the day you install, and watch Releases, not the comment section.

## 🚧 Limits

Honest edges, so nobody buys a fantasy:

- `Teleport` moves the client, not the server tick — long hops rubber-band.
- `Hitbox draw` needs fresh branch offsets; a day-one patch can grey it out.
- `Grab helper` covers grab-capable species only, pounce markers pounce-capable only.
- Growth multiplier is client-side: it feeds the same curve, it doesn't invent stats.
- No Linux, Proton or GeForce Now support.

## ❓ FAQ

<details>
<summary><b>Does it work on Evrima right now?</b></summary>

Against `0.21.x`, yes — and Legacy from the same build. After a patch, wait for the matching tag.
</details>

<details>
<summary><b>Is the game detecting it?</b></summary>

No kernel surface to scan: the build lives outside the process. Structural claim, not
immortality — the badge date is the thing to check.
</details>

<details>
<summary><b>Will viewers notice in a clip?</b></summary>

Not with `Stream mode` and `Silent assist`. `Aim assist` pulls visibly — that one shows.
</details>

<details>
<summary><b>Does the ESP show stage and mutations?</b></summary>

`H`, `J`, `SA`, `A`, `Prime`, `Frail` plus a mutation count, so a fresh adult is distinguishable
from a maxed Prime before you commit.
</details>

<details>
<summary><b>How does growth stack with the diet bonus?</b></summary>

Multiplicatively. Diet already reaches 300 %; the slider sits on top and `Diet mapper` keeps the
bars fed so the bonus stays.
</details>

<details>
<summary><b>Can I keep my config between versions?</b></summary>

Yes. Update in place — `isle.json` and `\profiles\` are untouched by an update.
</details>

<details>
<summary><b>30× growth — isn't that a giveaway?</b></summary>

On a busy server, obviously. `6×` reads as a good diet, `30×` reads as a cheat. One slider apart.
</details>

<details>
<summary><b>60 Hz laptop?</b></summary>

Default profile is under 2 ms. Start at ESP 150 m, `Hitbox draw` off, `Threat sort` on.
</details>

## 🔧 Troubleshooting

| Symptom | Fix |
|---|---|
| Menu doesn't appear | Borderless, launch `isle.exe` after the main menu |
| Draws show, input dead | Run as administrator, clear hook conflicts |
| Boxes drift off the model | Branch/RAM mismatch — install the matching tag |
| Black screen after a patch | Old build on a new branch |
| `Teleport` rubber-bands | Shorter hops, or `Fly` |
| Half the FPS | Cut `range`, disable `Occlusion mode` |
| Profile won't save | Read-only folder — leave `Program Files` |
| EAC kicks on launch | Verify in Steam, launch vanilla once, then the loader |

Escalation: [bug template](../../issues/new?template=bug.yml) with build tag, branch, server and
the tail of `\logs\isle.log`.
